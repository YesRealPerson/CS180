Part 2.1: Image sharpening

Notably high frequency information is associated with sharpness, as sudden large changes in pixel values tend to signify an edge. If we subtract the low-pass output from the original, a high-pass image is created instead. Adding this high pass image back to the original creates a sharpened image. Using this idea the "unsharp" mask filter can be constructed. If we understand a sharpend image as f+(f-f*g)=f+f-f*g=f(1+1-g). Which isn't entirely mathematically correct but works as a good analogy, meaning that we can apply sharpening by applying a filter that is a unit imulse subtracted by a gaussian.

Part 2.3/2.4: Image Blending

Finally, image blending. We can merge two images together by mixing the levels of their features together, but how do we get these feature levels? We can do this with a Laplacian stack. To define this let's start with the Gaussian stack, which is simply the image with a gaussian filter applied n times. Level 0 being the original image, and level 5 being filtered 5 times. If we subtract Gaussian level n by level n+1 we can effectively compute the features that belong to that frequency range this is level n of the Laplacian stack. Notably this is analogous to a band-pass filter! From here we can mask all the levels of the Laplacian stack and combine them with the other image's stack to create our merged image. Notably however if you write out the addition of our Laplacian stack you can expand it as: M(G0-G1)+...+M(GN-G{N+1}) you might notice that the last band of our frequency range is not included (being G{N+1}) as it is subtracted from the last laplacian level. Therefore to get our final image we mask it and add it to the end of the summation i.e. ...+MG{N+1}.
